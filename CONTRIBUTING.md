# Contributing

Thanks for helping keep this list useful.

- One pull request per addition (or a small group of related ones).
- Add the entry as a row in the most relevant table, in chronological order.
- Include: short author list, title, venue, year, tags, and a DOI or stable link. Add code and data links if they exist.
- Use the tags listed at the top of the README.
- Preprints are welcome; please update the entry when the paper is published.
- If you are unsure where something belongs, open an issue instead.
